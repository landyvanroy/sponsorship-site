# 全站设计风格规范（北京酷儿合唱团官网）

> 一句话概括这套设计：**纸上墨字** —— 纸色为底、老宋竖排、灰阶成层次、朱红一点作印。
> 本文件只描述设计风格与底线，不约定具体页面的版式；页面结构见 `src/app/components/Layout.jsx`。

---

## 1. 设计原则

1. **留白即版式**：不靠卡片、边框、阴影划分区域，靠空白与字号对比。
2. **竖排为魂，横排为用**：标题性、仪式性的文字（导航、题名、宣言式短句）用竖排（`writing-mode: vertical-rl`）；长文正文保持横排，保证阅读效率与可访问性。
3. **墨分五色**：只用灰阶表达层次，全站唯一彩色是印章朱红。
4. **克制**：无渐变、无投影、无圆角大卡片、无图标；装饰只允许"细线"与"印章"两种。

---

## 2. 色彩 Token（当前实际值）

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#faf8f4` | 页面底色（body） |
| `--paper-raise` | `#f4efe6` | 抬升底色（封面、占位图等大面积色块） |
| `--paper-slip` | `#fdfdfa` | 纸面最亮色（题签底、印章字色） |
| `--ink-1` | `#2c2a26` | 标题、正文主色（浓墨） |
| `--ink-2` | `#5a554b` / `#6b6a66` | 次要正文、引言（中墨） |
| `--ink-3` | `#9b988f` | 导航、页脚、辅助信息（淡墨） |
| `--ink-4` | `#c4c0b6` | 占位/禁用（极淡墨） |
| `--seal` | `#b03a2e` | 印章朱红：hover 强调、印章、栏目标签 |
| `--line` | `#e8e2d6` | 分隔细线（1px） |

规则：

- 除 `--seal` 外禁止引入任何彩色（包括链接蓝色）。
- 正文（`--ink-1/2`）对比度 ≥ 4.5:1；`--ink-3` 只允许用于 ≥ 14px 的辅助信息。
- hover 的唯一表达：文字变 `--seal`，或淡墨变浓墨；不加粗、不换背景。
- 注：以上值目前硬编码在 `style.css`，提取为 `:root` 变量为待办。

## 3. 字体

- Webfont：`KingHwaOldSong`（京華老宋體），构建期按用字动态子集化，回退栈 `"Songti SC", "SimSun", "Noto Serif CJK SC", serif`。
- 全站只用宋体系衬线；代码场景可用 `ui-monospace`；不用无衬线做标题。
- 字号基准：页面标题 30px / 竖排题名 26px / 正文 16–17px / 辅助 13–14px。行高宽松（横排 ≥ 1.9）。

---

## 4. 竖排规范

```css
.vertical {
  writing-mode: vertical-rl;
  text-orientation: upright;   /* 中文直立 */
  letter-spacing: 0.3–0.4em;   /* 字距明显 */
  line-height: 2.4;            /* 列间距由 line-height 提供 */
}
```

- 竖排文字一律 `--ink-2` 或 `--ink-3`，不用浓墨。
- 多列竖排阅读方向**自右向左**：最右列第一，DOM 顺序与视觉顺序一致。
- 对齐原则：**居右对齐、自上而下对齐**（竖排块宽度按内容收缩时用 `margin-left: auto` 靠右；`text-align: start` 保证列首对齐）。
- 列高以内容自然断行为准，不强行等高。

---

## 5. 版式与间距

- **页面框架**：左内容、右导航两栏（Layout.jsx）；内容区 max-width 720px，整体 max-width 960px 居中。
- **留白**：8px 基准整体放大——区块间距 ≥ 64px，页面上下留白 ≥ 96px。宁多勿少。
- **分隔**：默认只用空白；必须分隔时用 1px `--line` 细线，线长不超过内容宽的 1/3。
- **对齐**：横排左对齐；竖排顶部对齐。

---

## 6. 印章（全站唯一装饰元素）

- 形制：20–32px 见方，朱红 `--seal` 底、纸色字，或朱红描边空心；内文 1–4 字。
- **每页 ≤ 1 枚**，只出现在落款处（文末、题签内、页脚）。
- 一律 `aria-hidden="true"`；优先内联实现，避免额外图片请求。

---

## 7. 交互与动效

- 全站过渡统一 `transition: color .2s ease`；不做位移/缩放/弹跳动效。
- 链接 hover 变色不加粗；正文内链接可用 `text-underline-offset: 4px` 细下划线。
- 入场动效（如竖排列依次淡入）总时长 < 800ms，且尊重 `prefers-reduced-motion`。
- React 19 SSR 会自动为 `<img>` 注入 `<link rel="preload" as="image">`，属预期行为，无需处理。

---

## 8. 响应式原则

| 断点 | 处理 |
|---|---|
| ≥ 880px | 两栏框架：左内容 + 右竖排导航 |
| < 880px | 框架纵向堆叠，页头横排一行置顶 |
| < 640px | 竖排宣言类文字转横排；字距降为 0.1–0.2em；正文 15px |

---

## 9. 无障碍与底线

1. `--ink-3` 只用于辅助信息；所有正文对比度 ≥ 4.5:1。
2. `img` 必须有 alt；印章 `aria-hidden`。
3. 焦点态全站唯一：`:focus-visible { outline: 1px solid var(--seal); outline-offset: 3px; }`。
